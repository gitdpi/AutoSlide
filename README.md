# AutoSlide - 自动滑动屏幕应用

## 功能介绍

AutoSlide是一个安卓应用，用于自动滑动屏幕，主要应用场景是在需要看广告的场景中，通过自动滑动屏幕来累计观看时长。

### 核心功能
- 悬浮小图标控制：点击悬浮图标可开启/关闭自动滑动
- 自动滑动：每2-5秒随机执行一次从底部向上的滑动操作，避免显得机械
- 可拖动悬浮图标：根据需要调整悬浮图标的位置
- 前台服务：确保服务在后台稳定运行

## 权限说明

应用需要以下权限：
- `SYSTEM_ALERT_WINDOW`：用于显示悬浮图标
- `FOREGROUND_SERVICE`：用于在后台运行服务
- `BIND_ACCESSIBILITY_SERVICE`：用于执行滑动操作

## 使用方法

1. 安装并打开应用
2. 点击"启动自动滑动服务"按钮
3. 如果首次运行，会请求悬浮窗权限，请授予权限
4. 应用会检查无障碍权限，如果未开启，会引导用户进入设置页面开启
5. 开启无障碍权限后，返回应用，再次点击"启动自动滑动服务"按钮
6. 服务启动后，屏幕上会出现一个悬浮图标
7. 点击悬浮图标可开启/关闭自动滑动功能
8. 拖动悬浮图标可调整其位置
9. 点击"停止自动滑动服务"按钮可停止服务

## 技术实现

- **开发语言**：Java
- **最低支持版本**：Android 5.0 (API 21)
- **目标版本**：Android 14 (API 34)
- **主要组件**：
  - MainActivity：处理权限请求和服务控制
  - AutoSlideService：实现自动滑动和悬浮图标功能
  - AutoSlideAccessibilityService：使用辅助功能执行滑动操作

## 注意事项

- 应用使用辅助功能服务来执行滑动操作，需要用户在系统设置中开启无障碍权限
- 自动滑动功能可能会影响其他应用的正常使用，请在需要时开启
- 建议在观看广告等需要累计时长的场景中使用
- 每次应用启动时，会检查无障碍权限状态并提示用户

## 构建和安装

1. 使用Android Studio打开项目
2. 构建并运行应用到设备或模拟器
3. 按照上述使用方法操作
